# SpeckleLeJEPA 已确认决策

项目目标是在三通道显微细胞图像上复现 LeJEPA 自监督预训练。论文以 arXiv `2511.08544v3` 为准，作者代码参考工作区 `lejepa/` 中的提交 `c293d291ca87cd4fddee9d3fffe4e914c7272052`。官方最小示例中的在线分类探测器属于其评估设置，本项目的模型只包含自监督预训练目标。 [论文 v3](https://arxiv.org/html/2511.08544v3) · [官方源码](https://github.com/galilai-group/lejepa/tree/c293d291ca87cd4fddee9d3fffe4e914c7272052) · [论文阅读笔记](../../LeJEPA-v3-notes.md)

## 数据与样本语义

- 数据约有几十万张固定尺寸、约 1000×1000 的 RGB 显微原图，按两万余个基因类别组织，每类十几张图。一张原图通常含数个至约一百个实例，实例尺寸约为 100×100，一般不超过 128×128。
- 数据入口为已有 `ImageIndex` 的 NPY 索引。基因对应类别，图像路径与 polished mask 路径沿用 `ImageAnalyser.py` 的约定。mask 为单通道逐像素 16 位实例 ID，`0` 为背景。
- 预训练样本单位是细胞。以目标实例居中裁出固定大小底图，对目标外区域置零，再从同一底图生成大、小视图。两组裁剪都要包含足够的实际实例前景。
- 按基因分散组 batch。`n` 表示同一原图在同一个 batch 中最多贡献的不同细胞数，当前使用 `batch_size=256, n=1`。补充缓存优先选未在活跃池中出现的基因，必要时选活跃图数最少的基因。保持每个合格细胞每轮一次，允许细胞较多的原图在整轮贡献更多样本。
- 基因只参与组批，所有细胞在损失中等权。按基因分散会改变每步 SIGReg 所见的样本组成，因此它是需要记录的显微数据采样设置。`256` 在当前接口中是单个数据流的 batch；远端多卡时的全局和每卡 batch 口径尚待明确。

## 网络与运行环境

- 采用共享三通道 **ResNet-50** 和 **三层 Projector**。全局视图为 **96×96**，局部视图为 **48×48**。预训练的预测项与 SIGReg 作用于 Projector 输出，下游提取 Projector 前的骨干特征。
- 预测损失采用论文 §5.1 和作者伪代码中的全局中心形式。原文式 (6) 与式 (7) 的差是全局视图围绕中心的方差项，中心实现的选择已经落实到源码。两项损失都在当前 batch 计算，SIGReg 从第一步生效。 [论文 §5.1](https://arxiv.org/html/2511.08544v3#S5.SS1) · [公式核对](../../LeJEPA-v3-notes.md)
- CUDA 自动优先使用原生 BF16 混合精度，其余支持的 CUDA 设备使用 FP16 混合精度和梯度缩放。设备选择由实际训练设备决定。本机 Conda 环境用于功能测试，正式训练在远端运行，显存或吞吐判断以远端环境为准。
- 论文表 4 在 ImageNet-100 上采用三层投影头、关闭 predictor 和 SWA 时，ResNet-50 与 ViT-Ti/8 分别为 83.93% 和 80.37%。这说明该实验中采用 LeJEPA 后的最终成绩有差异。两骨干各自的同条件基线不足以判断谁从 LeJEPA 获益更多。 [论文表 4](https://arxiv.org/pdf/2511.08544v3#page=42)

## 当前实现默认值

| 项目 | 当前默认值 |
| --- | --- |
| 细胞底图与视图数量 | 128×128，2 个全局视图，2 个局部视图 |
| 全局裁剪 | 边长为实例外接框最长边的 0.90–1.20 倍，保留面积至少 75%，前景比例至少 15% |
| 局部裁剪 | 边长为实例外接框最长边的 0.35–0.65 倍，保留面积至少 5%，前景比例至少 45% |
| 投影头 | `2048 → 2048 → 2048 → 128`，前两层接 BatchNorm 和 ReLU |
| 损失与 SIGReg | `reg_weight=0.05`，256 条切片方向，`[0, 3]` 上 17 个积分点 |

裁剪阈值、底图尺寸、视图数量、投影维度与 SIGReg 参数是当前可配置默认值。裁剪阈值尚未在真实训练集上校准。优化器、学习率、调度、训练轮数与 checkpoint 策略留待训练入口确定。 [项目配置说明](../README.md)
